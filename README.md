# Лабораторная работа №2

Анализ успеваемости студентов на JavaScript.

Запуск:

```
node main.js
```

Структура:

- `data.js` - массив оценок студентов
- `calculateAverage.js` - средний балл
- `findTopStudent.js` - лучший студент
- `filterFailed.js` - список должников
- `addLetterGrade.js` - буквенные оценки
- `main.js` - сборка всех функций и вывод результата
